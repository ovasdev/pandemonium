# Medical Record — Медицинская карта

Ведение структурированной медицинской карты пользователя в памяти агента.

## Принцип работы

При каждом разговоре, содержащем медицинскую информацию о пользователе, **автоматически** (без напоминания) сохраняй или обновляй соответствующие записи в памяти.

## Структура карты

Медицинская карта хранится в файлах памяти агента (`memory/`) с типом `user` и префиксом `medical_` в имени файла.

### Основные разделы карты

| Файл | Содержание |
|------|-----------|
| `medical_profile.md` | Пол, возраст, рост, вес, ИМТ, группа крови, аллергии, хронические заболевания |
| `medical_history.md` | Анамнез: перенесённые заболевания, операции, травмы, госпитализации |
| `medical_family.md` | Семейный анамнез: заболевания родственников, наследственные риски |
| `medical_labs.md` | Результаты анализов и обследований с датами |
| `medical_medications.md` | Текущие и прошлые назначения, дозировки, реакции |
| `medical_lifestyle.md` | Образ жизни: питание, физическая активность, сон, вредные привычки, стресс |
| `medical_complaints.md` | Текущие жалобы и симптомы с датами |
| `medical_goals.md` | Цели по здоровью, план действий, динамика |

### Формат записей

Каждый файл памяти — стандартный формат с фронтматтером:

```markdown
---
name: medical-profile
description: Базовый медицинский профиль пользователя — пол, возраст, антропометрия, аллергии, хронические заболевания
type: user
---

## Базовые данные
- Пол: ...
- Возраст: ...
- Рост: ...
- Вес: ... (дата)

## Аллергии
- ...

## Хронические заболевания
- ...
```

## Правила ведения карты

1. **Автоматическая фиксация** — любая новая медицинская информация о пользователе сохраняется сразу, без запроса подтверждения.

2. **Датирование** — каждая запись с привязкой ко времени содержит абсолютную дату (не «вчера», а «2026-04-09»).

3. **Обновление, не дублирование** — если информация по разделу уже существует, обнови файл, не создавай новый. Например, новый результат анализа добавляется в `medical_labs.md`, а не в отдельный файл.

4. **Индексация** — после создания или обновления файла карты обнови `MEMORY.md`, добавив или скорректировав строку-указатель.

5. **Точность** — записывай только то, что пользователь сообщил явно. Не интерпретируй, не додумывай, не ставь диагнозы в карту без явного подтверждения.

6. **Конфиденциальность** — медицинские данные чувствительны. Не упоминай содержимое карты в контекстах, где это не запрошено.

7. **Динамика** — при повторных измерениях (вес, давление, анализы) сохраняй историю с датами для отслеживания тренда.

## Когда обновлять карту

- Пользователь сообщает о симптомах, жалобах, самочувствии
- Пользователь делится результатами анализов или обследований
- Пользователь рассказывает о диагнозе, назначении, лечении
- Пользователь упоминает свой образ жизни, питание, нагрузки, сон
- Пользователь сообщает антропометрические данные (вес, рост, давление)
- Пользователь рассказывает о семейном анамнезе
- Пользователь ставит цели по здоровью или сообщает о прогрессе

## Когда НЕ обновлять карту

- Теоретические вопросы о медицине без личного контекста
- Вопросы о здоровье третьих лиц (если не семейный анамнез)
- Информация, которая уже записана без изменений

## Пример работы

Пользователь: «У меня холестерин 6.2, врач сказал повышенный. Начал пить омега-3.»

Действия:
1. Обновить `medical_labs.md` — добавить: общий холестерин 6.2 ммоль/л (2026-04-10)
2. Обновить `medical_medications.md` — добавить: омега-3 (начало приёма 2026-04-10)
3. Обновить `medical_complaints.md` или `medical_goals.md` — гиперхолестеринемия, работа над снижением
4. Обновить `MEMORY.md` если появились новые файлы
