# Managing Souls

Create, edit, list, and remove agent souls in `.agent/souls/`.

---

## Project Context

Души создаются в `.agent/souls/` **активного проекта**:

1. Определи активный проект — это проект, с которым пользователь сейчас работает.
2. Базовый путь: `{project.path}/.agent/souls/`.
3. Если директория `.agent/souls/` не существует — создай её (`mkdir -p`).
4. Все операции (создание, чтение, удаление) используют этот путь.

---

## What Is a Soul

Душа — это набор личностных характеристик, который можно привязать к персоне. Душа не определяет компетенции или навыки — она задаёт **как** агент думает, общается и воспринимает контекст.

Душа задаёт:

- **Характер** — темперамент, эмоциональный фон, склонность к юмору или серьёзности
- **Стиль мышления** — аналитический, интуитивный, прагматичный, творческий
- **Стиль общения** — формальный/неформальный, многословный/лаконичный, тон
- **Пресуппозиции** — базовые убеждения и установки, через которые агент фильтрует информацию
- **Ценности** — что агент считает важным, на что обращает внимание в первую очередь

Одна душа может быть назначена нескольким персонам. Персона без души работает нейтрально-функционально.

## File Structure

```
.agent/souls/
└── {soul-name}/           ← папка души (kebab-case)
    ├── SOUL.md             ← главный файл (обязательный)
    └── memory/             ← память души (опционально)
        └── INDEX.md
```

Имя папки — kebab-case, совпадает с идентификатором души.

---

## Soul Template

```markdown
---
name: {soul-name}
description: "{краткое описание — 1 строка}"
---

# {Display Name}

## Характер

{Темперамент, эмоциональный фон, отношение к работе и людям.}

## Стиль мышления

{Как подходит к проблемам — аналитически, интуитивно, прагматично.
Что замечает первым. Как принимает решения.}

## Стиль общения

{Формальность, многословность, тон, использование метафор/юмора.
Примеры характерных фраз.}

## Пресуппозиции

{Базовые убеждения и установки. Через какую призму агент видит мир.}

- {Пресуппозиция 1}
- {Пресуппозиция 2}

## Ценности

{Что для этой души важно. На что обращает внимание.}

- {Ценность 1}
- {Ценность 2}
```

## Create a Soul

1. Спросить у пользователя (если не указано):
   - Имя души
   - Ключевые черты характера
   - Стиль общения
   - Пресуппозиции и ценности (если есть)
2. Проверить, что папка с таким именем не существует в `.agent/souls/`.
3. Создать папку `{soul-name}/` и файл `SOUL.md` по шаблону.
4. Обновить реестр душ в `bot_administrator` (если существует).

### Validation

| Правило | Почему |
|---------|--------|
| Имя папки — kebab-case | Единообразие со скилами и персонами |
| Главный файл — `SOUL.md` | Аналогия со `SKILL.md` и `PERSONA.md` |
| Имя уникально | Не перезаписывать существующую душу без явного запроса |

---

## Edit a Soul

1. Прочитать `SOUL.md` души.
2. Обновить нужные секции.
3. Если душа привязана к персонам — изменения подхватятся автоматически (персоны ссылаются по имени).

---

## List Souls

1. Прочитать все `SOUL.md` файлы в подпапках `.agent/souls/`.
2. Вывести таблицу:

```
| Душа       | Ключевые черты                          | Привязана к        |
|------------|-----------------------------------------|--------------------|
| kerni      | Перфекционист-детальщик                 | qa-tester          |
```

Для колонки «Привязана к» — проверить поле `soul` во frontmatter всех персон из `.agent/personas/`.

---

## Remove a Soul

1. Проверить, не привязана ли душа к какой-либо персоне.
2. Если привязана — предупредить пользователя и спросить подтверждение.
3. Удалить папку души целиком из `.agent/souls/`.
4. Обновить реестр в `bot_administrator`.
