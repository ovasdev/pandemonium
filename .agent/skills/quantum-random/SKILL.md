# Квантовая кость

Бросает настоящие квантовые случайные числа, рождённые из флуктуаций вакуума.

---

## Как бросить

```bash
.pandemonium/tools/quantum_random.sh <количество> [from] [to]
```

- `количество` — сколько чисел (>= 1)
- `from` — нижняя граница диапазона (по умолчанию 0)
- `to` — верхняя граница диапазона (по умолчанию 255)

---

## Примеры

```bash
# Бросок шестигранного кубика (1–6)
.pandemonium/tools/quantum_random.sh 1 1 6

# Три броска d20
.pandemonium/tools/quantum_random.sh 3 1 20

# Монетка (1 = орёл, 2 = решка)
.pandemonium/tools/quantum_random.sh 1 1 2

# Пять сырых квантовых чисел (0–255)
.pandemonium/tools/quantum_random.sh 5

# Число от 100 до 999
.pandemonium/tools/quantum_random.sh 1 100 999
```

---

## При ошибке

Если скрипт завершился с ненулевым кодом — сообщи пользователю:

> Квантовая кость недоступна.

Не подменяй результат псевдослучайными числами. Квантовая кость — это квантовая кость.

---

## Как это работает

Скрипт получает сырые квантовые байты (0–255) от QRNG API и маппит их в заданный диапазон `[from, to]` через остаток от деления: `from + (n % range)`, где `range = to - from + 1`.

Для идеальной равновероятности используется **rejection sampling**: если `range` не делит 256 нацело, байты, которые создают перекос, отбрасываются. Порог отсечения: `threshold = 256 - (256 % range)`. Принимаются только байты `< threshold`, их количество всегда кратно `range` — каждое значение строго равновероятно.

Если отброшенных байтов оказалось много и набранных не хватило — скрипт автоматически запрашивает дополнительную порцию (с запасом ~20%).

## Ограничения

- Сырой источник: uint8 (0–255), маппинг в произвольный диапазон через rejection sampling
- Лимит API: 1024 числа за запрос (батчинг автоматический)
- Требуется интернет, `curl`, `jq`
- Основной источник: [LfD QRNG](https://www.lfdr.de/QRNG/) (Германия)
- Фолбэк: [ANU QRNG](https://qrng.anu.edu.au/) (Австралия)
