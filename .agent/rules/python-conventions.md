# Скилл: Python-конвенции проекта

## Общие правила

- Python 3.12+. Используй современный синтаксис: `type X = ...`, `match/case`, `X | Y` для union-типов.
- Типизация обязательна для всех публичных функций и методов.
- Используй `dataclass` или `pydantic.BaseModel` для структур данных. Не используй `TypedDict`.
- Асинхронный код: `async/await` везде где есть I/O.
- Не используй `print()` для логирования — только `logging`.

## Структура модулей

- Каждый модуль имеет `__init__.py` с экспортами.
- Один класс/ответственность на файл (допустимы вспомогательные dataclass-ы рядом).
- Импорты: stdlib → third-party → local, разделённые пустой строкой.

## Зависимости

- Менеджер пакетов: **uv**
- Добавление зависимости: `uv add package_name`
- Запуск: `uv run python -m pandemonium.tgbot`
- Зависимости описаны в `pyproject.toml`

## Обработка ошибок

- Собственные исключения наследуй от базового `PandemoniumError`.
- Не глуши исключения (`except: pass`). Логируй и пробрасывай или обрабатывай.
- В asyncio-коде: всегда обрабатывай `CancelledError` — не подавляй его.

## Тесты

- Фреймворк: `pytest` + `pytest-asyncio`.
- Файлы тестов: `tests/test_{module}.py`.
- Запуск: `uv run pytest`.
