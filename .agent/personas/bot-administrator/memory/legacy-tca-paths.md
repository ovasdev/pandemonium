Старые данные проекта (до переименования tca → pandemonium) лежат в `~/.tca/`: конфиг, сессии, tools. Активный конфиг — `~/.pandemonium/config.yaml` (или `config.yaml` в корне проекта). При проблемах с путями — проверить, не указывает ли что-то на `~/.tca/`.
