# Скилл: Работа со спринтом

## Когда использовать

Когда пользователь просит выполнить спринт (например, "выполни спринт 1" или "sprint 2").

## Порядок действий

1. **Прочитай документацию проекта** (если ещё не читал в этой сессии):
   - `docs/requirements.md` — требования
   - `docs/architecture.md` — архитектура

2. **Прочитай файл спринта**:
   - Спринты лежат в `docs/sprints/`
   - Файлы: `01-foundation.md`, `02-claude-process.md`, и т.д.

3. **Проверь текущее состояние проекта**:
   - Какие файлы уже существуют
   - Что реализовано в предыдущих спринтах
   - `git log` — что уже закоммичено

4. **Реализуй задачи спринта последовательно**:
   - Следуй порядку задач в файле спринта
   - После каждой крупной задачи — проверяй что код работает
   - Не пропускай задачи, даже если они кажутся тривиальными

5. **Проверь критерий готовности**:
   - Каждый спринт содержит секцию "Критерий готовности"
   - Убедись что все пункты выполнены
   - Запусти проект / тесты если указано

6. **Закоммить результат**:
   - Коммит с сообщением: `sprint N: краткое описание`
   - Только после проверки что всё работает
