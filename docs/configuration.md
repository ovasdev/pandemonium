# Конфигурация

Pandemonium bot настраивается через YAML-файл, валидируемый pydantic 2.x.

## Расположение конфига

Путь к конфигу определяется в порядке приоритета:

1. CLI-аргумент: `--config /path/to/config.yaml`
2. Переменная окружения: `PANDEMONIUM_CONFIG`
3. По умолчанию: `config.yaml` в корне проекта

Шаблон: `config.example.yaml`. Рабочий `config.yaml` добавлен в `.gitignore`.

## Полный пример

```yaml
telegram:
  bot_token: "123456:ABC-DEF..."

allowed_users:
  - telegram_id: 123456789
    name: "Alice"
  - telegram_id: 987654321
    name: "Bob"

projects:
  - id: "my-app"
    name: "My Application"
    path: "/home/user/projects/my-app"
  - id: "another"
    name: "Another Project"
    path: "/home/user/projects/another"

storage:
  base_path: "~/.pandemonium/sessions"

token_budget:
  per_request_limit: 0

timeouts:
  request_max_seconds: 1800
```

## Секции

### telegram

| Поле | Тип | Обязательно | Описание |
|------|-----|:-----------:|----------|
| `bot_token` | string | да | Токен Telegram-бота от @BotFather |

### allowed_users

Список пользователей, которым разрешён доступ к боту (whitelist). Все остальные игнорируются middleware авторизации.

| Поле | Тип | Обязательно | Описание |
|------|-----|:-----------:|----------|
| `telegram_id` | int | да | Telegram ID пользователя |
| `name` | string | да | Отображаемое имя (используется в логах и протоколах) |

### projects

Список проектов, в контексте которых бот может запускать Claude Code. Первый проект в списке — дефолтный.

| Поле | Тип | Обязательно | Описание |
|------|-----|:-----------:|----------|
| `id` | string | да | Уникальный идентификатор проекта |
| `name` | string | да | Отображаемое имя |
| `path` | Path | да | Абсолютный путь к директории проекта. Валидируется при старте — директория должна существовать |

### storage

| Поле | Тип | По умолчанию | Описание |
|------|-----|:------------:|----------|
| `base_path` | Path | `~/.pandemonium/sessions` | Корневая директория для хранения протоколов сессий. Поддерживает `~` — раскрывается автоматически |

Внутри `base_path` создаётся поддиректория `uploads/` для файлов, полученных от пользователя через Telegram.

### token_budget

| Поле | Тип | По умолчанию | Описание |
|------|-----|:------------:|----------|
| `per_request_limit` | int | `0` | Максимальное количество токенов на один запрос. `0` — без ограничений |

### timeouts

| Поле | Тип | По умолчанию | Описание |
|------|-----|:------------:|----------|
| `request_max_seconds` | int | `1800` | Максимальное время выполнения запроса в секундах (30 минут по умолчанию) |

## Валидация

Конфиг валидируется при запуске через pydantic-модель `AppConfig`. Ошибки выбрасываются как `ConfigError` (наследник `PandemoniumError`):

- Отсутствие обязательных полей
- Некорректный YAML-синтаксис
- Несуществующая директория в `projects[].path`
- Невалидные типы данных

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `PANDEMONIUM_CONFIG` | Путь к конфигу (альтернатива `--config`) |
| `PANDEMONIUM_BOT_TOKEN` | Устанавливается ботом при запуске Claude Code — используется для отправки файлов |
| `PANDEMONIUM_CHAT_ID` | Устанавливается ботом при запуске Claude Code — ID чата текущей сессии |
| `PANDEMONIUM_SEND_FILE` | Устанавливается ботом — путь к скрипту отправки файлов |
