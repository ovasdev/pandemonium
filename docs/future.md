# Pandemonium Telegram bot — Планы на будущее

## Мультипроектность

- Регистрация нескольких проектов в конфиге.
- Выбор проекта через команду `/project` или inline-кнопки.
- Параллельные запросы: один активный запрос на каждый проект одновременно.

## Очередь задач

- Если пользователь отправляет запрос при занятом агенте — запрос ставится в очередь.
- Приоритеты, отображение позиции в очереди.

## Persistent-сессии

- Сессия Claude Code сохраняется между запросами (через `--resume`).
- Каждый проект имеет свою сессию.
- Команда `/new_session` — сбросить сессию и начать заново.

## Медиа-ввод

- Поддержка скриншотов: пользователь отправляет изображение в Telegram, бот передаёт его Claude Code.
- Claude Code мультимодальный — может анализировать скриншоты UI, ошибок, дизайн-макетов.

## Мультипользовательность

- Несколько пользователей с индивидуальными проектами и бюджетами токенов.
- Роли: admin (управляет конфигом), user (только запросы).
